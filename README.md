# IPL Data Analysis

## Overview
This project analyzes IPL cricket data using Python, Pandas, SQL, and visualization libraries.

## Technologies Used
- Python
- Pandas
- SQLite
- Matplotlib
- Seaborn
- Google Colab

## Analyses Performed
- Most successful IPL teams
- Top run scorers
- Top wicket takers
- Venue analysis
- Toss impact analysis
- Player of the match analysis

## Project Structure

```plaintext
data/
notebooks/
images/
```

## Key Insights
- Mumbai Indians and CSK are among the most successful teams.
- Certain venues host significantly more IPL matches.
- Toss results can influence match outcomes.
