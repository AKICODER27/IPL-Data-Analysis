# IPL Data Analysis

## Overview
This project analyzes Indian Premier League (IPL) match data using Python, SQL, and data visualization libraries. The project focuses on extracting insights related to team performance, player statistics, venue trends, and toss impact.


## Technologies Used
- Python
- Pandas
- SQLite
- Matplotlib
- Seaborn
- Google Colab


## Analyses Performed
- Most Successful IPL Teams
- Top Run Scorers
- Top Wicket Takers
- Venue Analysis
- Toss Impact Analysis
- Player of the Match Analysis

## Dataset
The dataset used in this project was taken from Kaggle:

https://www.kaggle.com/datasets/patrickb1912/ipl-complete-dataset-20082020

CSV files used:
- matches.csv
- deliveries.csv

## Key Insights
- Mumbai Indians and Chennai Super Kings are among the most successful IPL teams.
- Certain stadiums host significantly more IPL matches.
- Top players consistently dominate batting and bowling statistics.
- Toss results can influence match outcomes.
